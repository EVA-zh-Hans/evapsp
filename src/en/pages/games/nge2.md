## Introduction

*Shinseiki Evangelion 2: Tsukurareshi Sekai* is a 2006 PSP simulation/adventure game where you interact with the cast and progress through the story. This project aims to produce a complete, reproducible Simplified Chinese patch, focusing on text structure analysis, translation management, and automated patch building.

## Translation notes

- Beta patches are released (v2.1.x-beta) for both ULJS00061 and ULJS00064
- Includes translated memory text, a scrolling translator credits roll, and fixed classified-info display
- Under active development; testers and translators welcome

## How to use

1. Download the `xdelta` patch matching your game version
2. Apply it to the original Japanese ISO with [Xdelta patcher](https://kotcrab.github.io/xdelta-wasm/)
3. Copy the patched ISO to your PSP or run it in PPSSPP

## Contribute

Translation happens on [ParaTranz](https://paratranz.cn/projects/10882); progress and discussions live in [EVA-zh-Hans/nge_2_re](https://github.com/EVA-zh-Hans/nge_2_re).
